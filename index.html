VALORANT COMMUNITY PROJECT

🎮 VALORANT Discord Leaderboard

A Discord bot designed for VALORANT community servers. Members can register their VALORANT accounts and view a community leaderboard with competitive rank and ranked rating (RR).

⚙️ How it works

1. Register

A Discord member uses the /register command to register their VALORANT account.

2. Connect account

The planned production version will use Riot's approved authentication / RSO flow to connect the player's VALORANT account.

3. Retrieve competitive information

After the appropriate authorization and API access, the bot can retrieve supported competitive information such as rank and ranked rating.

4. Leaderboard

The bot displays registered accounts in a Discord leaderboard so community members can compare their current competitive progress.

5. Multiple accounts

A Discord member can register more than one VALORANT account.

💬 Example Discord Flow

/register Riot ID: Zozo Tag: 1234 [ Continue ] ✅ Account connected Zozo#1234

🤖 Current Prototype

✅ /register opens a registration form.
✅ Registered Riot IDs and tags are stored.
✅ /leaderboard displays registered accounts.

🔗 Planned Riot Integration

The production version is planned to use Riot's approved authentication and API mechanisms where required.

Player information will be used for connecting accounts and displaying supported competitive information in the Discord community leaderboard.

The project is not intended to provide an item shop checker or professional esports data.
