PUBLIC VALORANT COMMUNITY PROJECT

🎮 VALORANT Community Leaderboard

A public Discord bot project designed for VALORANT communities. Discord servers can use the bot to create community leaderboards showing supported competitive information for players who have explicitly connected and authorized their Riot account.

🌐 Project Purpose

This project is designed to be usable by multiple VALORANT Discord communities rather than being limited to a single private server.

Community members can connect their own VALORANT account and choose to share supported competitive information with the Discord community leaderboard.

⚙️ How it works

1. Join a supported Discord community

A Discord server can add the bot and enable the community leaderboard.

2. Connect a VALORANT account

The planned production version will use Riot Sign On (RSO) and OAuth so the player can securely authenticate with Riot.

3. Player opt-in

Players must explicitly authorize the application before their supported player information can be displayed.

4. Retrieve supported competitive information

After authorization and appropriate API access, the bot can retrieve supported competitive information such as rank and ranked rating.

5. Community leaderboard

Authorized players can appear on the Discord community leaderboard so members can compare their competitive progress.

6. Multiple accounts

The planned system can support multiple VALORANT accounts where permitted by the account-linking flow.

🔄 Riot Sign On / OAuth integration is planned for the production version.

🔐 Player Privacy & Opt-In

Player information will not be displayed through the production application unless the player has explicitly opted in and authorized the application through Riot Sign On (RSO).

Account linking allows supported player information to be displayed to other members of the participating Discord community.

🔗 Planned Riot Integration

The production version will use Riot's approved authentication and API mechanisms where required.

The project is intended for community leaderboards and supported competitive information. It is not intended to provide an item shop checker, scouting functionality, or professional esports data.

Riot API access and RSO functionality are subject to Riot's approval and developer policies.
